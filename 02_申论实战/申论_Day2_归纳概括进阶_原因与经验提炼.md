# 申论第 2 课：归纳概括进阶 —— 如何戒掉“自创词”，从案例中扒出满分原词？

> **针对你 Day 1 暴露的核心痛点**：
> 你昨晚第一道题拿了 **11/15 分（73.3%）**，最大的失分点是：**明明看懂了材料意思，却习惯用自己的“程序员/职场日常用语”（如“未考虑交互逻辑”）去替换材料里的黄金规范词（如“缺乏适老化设计”、“数据孤岛”、“建而不用”）**。
> 今晚我们的唯一目标：练就**“原词照妖镜”**与**“纯案例故事提炼法”**，把小题得分率推上 **85%+（13/15分）**！

---

## 一、 为什么阅卷老师不认你的“自创同义词”？

再强调一次阅卷场的物理规则：
阅卷员屏幕右侧的标准答案只有冷冰冰的几个词：`数据孤岛（2分）`、`适老化（2分）`、`多头盖章/协同不足（2分）`、`建而不用（2分）`。
当你写“未考虑交互逻辑”时，阅卷员在 8 秒扫视中根本来不及思考“交互逻辑是不是等于适老化”，他没看到“适老”两个字，这 2 分就直接飞了！

### 铁律：只要材料里本身就有四字成语、双引号词、动宾规范短语，100% 原封不动照抄！一个字都不要改！

## 二、 什么时候才需要你“自己提炼词”？（纯口语案例转化表）

只有当材料是一段**纯大白话的村民/市民采访、或者纯讲故事的案例**，里面没有任何规范词时，才需要你把“大白话故事”翻译成“机关标准词”。

请背熟下面这张**《四川省考申论案例故事 $\rightarrow$ 机关规范词秒转表》**：

| 材料里的故事 / 村民大白话 | 你写在答题卡上的【高分规范总括词】 |
| :--- | :--- |
| “王大妈说手机字太小看不清，点来点去找不到按钮，还不如去窗口排队” | **缺乏适老化与无障碍设计，操作繁琐，用户体验差** |
| “张老板办个餐饮证，既要去市场监管局，又要去生态环境局、城管局，盖了8个章跑了半个月” | **跨部门协同联动不足，审批环节繁琐，多头管理** |
| “镇上花50万请外包公司建了个智慧农业大屏，除了领导视察开一下，平时一直黑着屏” | **脱离实际需求，搞形式主义/形象工程，建而不用、资源浪费** |
| “村里年轻人都出去打工了，剩下的老头老太太连智能手机都不会用，更别说搞电商直播了” | **农村空心化/老龄化严重，专业复合型/数字技能人才匮乏** |
| “今年看隔壁村种阳光玫瑰赚钱，全村跟着砍了桃树种葡萄，结果第二年价格暴跌烂在地里” | **产业同质化严重，盲目跟风，缺乏统筹规划与市场风险预警** |
| “县里环保局今天来查一次罚500，过了这阵风企业半夜照样偷偷排污，因为违法成本太低了” | **运动式执法，日常长效监管机制缺失，违法成本低、震慑力不足** |
| “我们想修冷库，但镇财政没钱，银行嫌农村抵押物不够不肯贷款，大企业也不愿来投” | **资金保障不足，融资渠道单一，社会资本参与度低** |
| “农产品质量好，但出了村连个像样的包装和商标都没有，只能按几毛钱一斤卖给二道贩子” | **品牌意识淡薄，附加值低，产业链条短（缺乏精深加工）** |

## 三、 今晚（21:30 - 23:00）实战通关标准

今晚我们将直接挑战一道 **四川省考（省市综合管理卷）真题级归纳概括题（概括“成功经验/主要做法”或“深层原因”）**，你的作答必须同时满足以下 4 条军规：
1. **分条换行标号**：严格写成 `1. …… \n 2. …… \n 3. …… \n 4. ……`。
2. **冒号前必有 4~8 字前置总括词**：如 `1. 强化顶层设计：`、`2. 推动数字赋能：`。
3. **材料里的双引号词、四字短语零遗漏照抄**。
4. **字数控制在红线的 90%~100% 之间**（要求 200 字就写 185~200 字，绝不写 120 字就停笔）。
