# 申论第 3 课：提出对策题 —— 省市卷“问题反推 + 药方扩充”满分法则

> **题型地位**：在四川省考（省市综合管理卷）中，**提出对策题（或“问题+对策”复合题）** 属于必考题型（通常 15~20 分）。
> **阅卷铁律**：如果说“归纳概括题”考的是**照抄与提炼**，那么“提出对策题”考的就是**“针对材料痛点，一对一开出具体、可落地的机关药方”**！

---

## 一、 审题第一关：这道题到底要不要先写“问题”？（生死审题！）

拿到一道对策题，前 10 秒先看题干怎么问，分清以下两类：

### 1. 【一问两答型（必须先写问题，再写对策！）】
* **标志词**：
  * “请梳理给定资料X中反映的**问题**，并提出**解决措施/建议**。”
  * “针对资料中存在的**不足/困境**，提出**改进对策**（要求：**问题明确**，措施得当）。”
  * *(🚨注意：只要“要求”里出现了“**问题明确/痛点清晰**”这四个字，哪怕题干只问“提出对策”，也必须先用 1/3 篇幅写问题，再用 2/3 篇幅写对策！)*
* **标准排版格式（两段式）**：
  > **问题**：1. ……；2. ……；3. ……。（占约 1/3 字数）
  > **对策**：1. **核心药方词**：具体动作A，具体动作B。2. **核心药方词**：……（占约 2/3 字数）

### 2. 【单问直答型（直接写对策，不单独列问题！）】
* **标志词**：题干只问“请就如何推进……提出你的对策/建议”，且要求里只有“针对性强、具体可行”，没有“问题明确”。
* **标准排版格式**：直接分条列 `1. 2. 3. 4.` 写对策！

---

## 二、 对策从哪来？（考场“三步找药法”）

千万不要一上来就靠自己脑子凭空瞎编“加强宣传、加大投入”！考场上的满分对策 **80% 都藏在材料里**！

### 第一步：直接抄材料里的“现成药方”（占 40% 分数）
材料里如果出现了：**专家学者的建议、外省/外地成功经验做法、领导讲话要求、“应当/必须/亟须/建议/通过……”**，直接原封不动抄下来变成你的对策！

### 第二步：把材料里的“具体问题/原因”直接反过来写（占 50% 分数，核心基本功！）
材料里有一条痛点，你就必须在答案里给它配一条解药（**一对一精准靶向，绝不漏掉任何一个痛点！**）：

| 材料里的具体问题（痛点） | 一秒反推的【精准对策（解药）】 |
| :--- | :--- |
| “各部门数据接口不一，各自为政，缺乏沟通” | **统一数据标准与接口规范，搭建跨部门信息共享平台，健全协同联动机制。** |
| “农产品检测标准空白，小作坊无证经营，抽检走过场” | **健全行业质量标准体系，严格市场准入审批，强化常态化随机抽检与联合执法。** |
| “老旧小区改造资金缺口大，单靠财政兜底难以为继” | **拓宽多元融资渠道：加大财政专项补贴，引入社会资本（PPP模式），引导居民合理共担。** |
| “基层农技人员年龄老化，不懂智慧农业设备操作” | **建强专业人才队伍：引进高层次复合型人才，开展常态化数字技能培训，完善基层激励考核机制。** |
| “村民怕担风险不敢种新品种，对惠农政策一问三不知” | **强化政策宣传与示范引领：通过线上线下多渠道精准宣讲政策，发挥党员致富带头人示范效应，健全农业保险兜底机制。** |

### 第三步：用“主体 + 手段 + 内容 + 效果”把干瘪的词扩充丰满（占 10% 分数）
* ❌ **干瘪低分写法（太假大空）**：“1. 要加强监管。”（阅卷老师：怎么加强？谁去监管？监管什么？只给1分！）
* ✅ **丰满满分写法（省市卷标准）**：“1. **强化全链条常态监管**：联合市监、公安等部门开展专项整治，利用大数据智能监测排查隐患，依法严厉查处违规行为，提高违法成本。”

## 三、 省市综合管理卷“六大万能黄金药方库”（背熟直接套！）

当你在考场上需要给对策加一个漂亮的**“4~6字前置总括词”**时，直接从下面这 6 个抽屉里拿：

1. **【顶层制度与标准】**：**健全制度规范 / 强化顶层设计**（完善法律法规、出台行业技术标准、细化配套实施细则、明确权责清单）。
2. **【监管与执法】**：**强化常态监管 / 严格执法问责**（建立跨部门联合执法机制、实施“双随机一公开”抽查、畅通群众举报监督渠道、列入黑名单实施联合惩戒）。
3. **【资金与硬件设施】**：**加大要素保障 / 完善基础设施**（设立财政专项引导基金、撬动金融信贷与社会资本参与、升级改造冷链物流/数字化硬件设施）。
4. **【技术与产业创新】**：**坚持科技赋能 / 深化数字转型**（深化“政产学研用”协同攻关、搭建智慧政务/大数据平台、延伸精深加工产业链、打造区域公用品牌）。
5. **【人才队伍建设】**：**建强人才支撑 / 激发育才活力**（拓宽柔性引才绿色通道、开展订单式靶向技能培训、优化职称晋升与薪酬激励保障）。
6. **【宣传引导与服务】**：**创新宣传引导 / 优化便民服务**（线上新媒体+线下网格员全覆盖宣讲、选树典型示范引领、开展适老化与帮办代办暖心服务）。
