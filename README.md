## 🔄 跨设备同步指令（公司 <-> 家里）

1. **在家里电脑首次拉取项目**：
   ```bash
   git clone <你的GitHub仓库地址>
   ```
2. **每次开始学习前（拉取最新进度）**：
   ```bash
   git pull
   ```
3. **每次学习结束后（保存并推送到 GitHub）**：
   ```bash
   git add .
   git commit -m "update: 每日备考进度更新"
   git push
   ```
