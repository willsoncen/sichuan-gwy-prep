# 判断推理 Day 2（午休抢分卡）：定义判断、类比推理与翻译推理铁律

> **适用时段**：每日 12:30 - 13:10（40分钟午间刷题前先花 8 分钟看透本卡，直接按规则秒题！）
> **核心目标**：拒绝凭感觉读题，用“要素比对”和“形式逻辑公式”把正确率锁死在 **80%+**。

## 一、 定义判断（四川省考 8~10 题）：命题人“3真1假”要素一刀切法

### 1. 命题人是怎么造假选项的？
定义判断题干往往长达 150 字，包含一堆晦涩的专业术语。但命题人在编造 3 个错误选项时，**绝对不会全盘皆错，而是故意改掉其中 1 个要素（主体、条件/方式、目的/结果、客体）**。
如果你通读全文凭“感觉像不像”做题，既慢又容易掉坑！

### 2. 考场 30 秒破局动作（拿笔圈 4 个要素）
读题干时，**不要读懂它的学术原理**，只拿笔圈出以下 4 个钩子，然后直接看选项排除：

| 要素钩子 | 题干标志词 | 命题人常设陷阱（一刀切排除！） |
| :--- | :--- | :--- |
| **① 主体（谁干的）** | **行政机关、司法机关、人民法院、商业银行、企业、个人、第三方机构** | 题干规定是“行政机关（政府）”，选项 A 写的是“某行业协会”或“某国企” $\rightarrow$ **主体不符，3秒直接排除！** |
| **② 目的/结果（为了啥/干成啥）** | **以……为目的、旨在……、为了谋取不正当利益、从而导致……、造成……后果** | 题干要求“以营利为目的”，选项 B 是“公益免费发放”；题干要求“最终达成和解”，选项 C 是“正在协商中（结果未发生）” $\rightarrow$ **直接排除！** |
| **③ 方式/条件（怎么干的/在什么前提下）** | **通过……手段、在……情况下、利用……、未经……同意、自愿、强制** | 题干写“在不知情的情况下”，选项 D 写“经双方协商一致” $\rightarrow$ **条件相反，直接排除！** |
| **④ 拆词同义法（遇到短定义）** | 定义词本身是偏正短语，如**“替代性强化”、“绿色壁垒”、“次生灾害”** | 直接拆开字面意思：**“次生”** = 必须是由前一个灾害引发的第二个灾害（如地震引发海啸，单纯刮台风就不是次生）。 |

## 二、 类比推理（四川省考 5~10 题）：造句子 + 二级辨析底牌

类比推理每道题必须在 **25 秒内** 解决！

### 1. 第一步：横向造最简句子（90% 的题靠造句排除 2 个选项）
* **全同关系**（同一个东西）：`芙蓉城：成都`、`土豆：马铃薯`、`家父：令尊（注意自称与敬称！）`。
* **并列关系（矛盾 vs 反对）**：
  * **矛盾并列（非此即彼，没有第三种可能）**：`生：死`、`男：女`、`金属：非金属`、`对称：不对称`。
  * **反对并列（除了A和B还有别的）**：`红：白`（还有黑黄）、`赞成：反对`（还能弃权）。
* **包容关系（种属 vs 组成）—— 四川极高频！**
  * **种属关系（A 是 B 的一种）**：`苹果：水果`、`四川：省份`。
  * **组成关系（A 是 B 的一部分，不能说 A 是一种 B）**：`轮胎：汽车`、`成都：四川`（成都是四川的一部分，不能说成都是一种四川！）。
* **交叉关系（有的A是B，有的B是A）**：`党员：大学生`、`军人：医生`、`国有企业：上市公司`（判定口诀：两边都能造出“有的A是B，有的A不是B”）。

### 2. 第二步：当剩两个选项一模一样时，祭出命题人“二级辨析四张底牌”
1. **【原材料：成品】必看：物理变化 vs 化学变化**
   * **物理变化**（本质没变，还能看出原样）：`木材：桌椅`、`玉石：玉镯`、`棉花：棉布`。
   * **化学变化**（发酵/燃烧/煅烧，本质变了）：`高粱：白酒`、`黄豆：酱油`、`黏土：瓷器`、`树枝：木炭`。
2. **【成语关系】必看：感情色彩（褒义 / 贬义 / 中性） + 词内部结构**
   * 例：`孜孜不倦（褒）` vs `连篇累牍（贬）`；`守株待兔（主谓+动宾）` vs `刻舟求剑（动宾+动宾）`。
3. **【动宾/主谓关系】必看：主体是否一致（同一个人干的，还是两个人干的）**
   * 例：`审查：批准`（都是上级机关干的，主体一致） vs `申请：批准`（下级申请，上级批准，主体不一致！）。
4. **【命名方式】**：按形状命名（马尾松）、按功能命名（减速带）、按颜色命名（白鹤）。

## 三、 逻辑判断之“翻译推理”（必考 2 题，纯送分公式！）

只要题干中出现 `如果……那么……`、`只要……就……`、`只有……才……`、`除非……否则不……`，**严禁靠日常语感理解**，直接翻译成箭头符号 $A \rightarrow B$！

### 1. 三大翻译口诀（背熟直接默写）

| 口诀名称 | 关联词特征 | 翻译符号 | 举例 |
| :--- | :--- | :---: | :--- |
| **① 前推后** | **如果** $A$，**那么** $B$<br>**只要** $A$，**就** $B$<br>所有 $A$ 都是 $B$ / $A$ 离不开 $B$ | $$A \rightarrow B$$ | “只要资料分析对13道，行测就能上70分”<br>翻译：$\text{资料13道} \rightarrow \text{行测70分}$ |
| **② 后推前** | **只有** $A$，**才** $B$<br>**不** $A$，**不** $B$<br>$B$ 的**前提/基础/必要条件/关键**是 $A$ | $$B \rightarrow A$$ | “只有深入基层，才能写出好报告”<br>翻译：$\text{好报告} \rightarrow \text{深入基层}$（谁是才字后面，谁放箭头前！） |
| **③ 否一推一**<br>*(选言命题)* | **或者** $A$，**或者** $B$（至少有一个真）<br>**除非** $A$，**否则不** $B$ | $$\neg A \rightarrow B$$<br>*(否定一个必肯定另一个)* | “除非努力，否则不能上岸”<br>翻译：$\text{上岸} \rightarrow \text{努力}$（否定了“努力”，就推“不能上岸”） |

---

### 2. 两大黄金推理法则（考场唯一合法变形！）

一旦写出 $A \rightarrow B$，在考场上只有以下两种推理是 **100% 正确** 的：

1. **【逆否等价定律】：肯前必肯后，否后必否前；否前、肯后全都是废话（推不出确定结论）！**
   $$A \rightarrow B \quad \Longleftrightarrow \quad \neg B \rightarrow \neg A$$
   * 例：已知 $\text{考上成都公务员} \rightarrow \text{通过笔试}$。
   * ✅ **肯前肯后**：张三考上了 $\rightarrow$ 张三一定通过了笔试。
   * ✅ **否后否前**：李四没通过笔试 $\rightarrow$ 李四一定没考上。
   * ❌ **否前错误**：王五没考上 $\rightarrow$ 能推出他没过笔试吗？不能！（可能过了笔试但面试挂了）。
   * ❌ **肯后错误**：赵六通过了笔试 $\rightarrow$ 能推出他一定考上了吗？不能！

2. **【德·摩根定律（去括号变号）】**：
   * $\neg (A \text{ 且 } B) \Longleftrightarrow \neg A \text{ 或 } \neg B$
   * $\neg (A \text{ 或 } B) \Longleftrightarrow \neg A \text{ 且 } \neg B$
   * *口诀：负号进括号，“且”变“或”，“或”变“且”！*
