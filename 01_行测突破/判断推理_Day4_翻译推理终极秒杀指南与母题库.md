## 一、 翻译推理四大必杀规则图解

### 规则 1：前推后（$A \rightarrow B$）
* **关联词**：
  * 如果 $A$，那么 $B$；只要 $A$，就 $B$；一旦 $A$，则 $B$；为了 $A$，必须 $B$
* **动作**：看到谁在“如果/只要”后面，谁就是前件，直接画箭头指向后件！

### 规则 2：后推前（$B \rightarrow A$）
* **关联词**：
  * **只有 $A$，才 $B$**（🚨 核心考点：谁在“才”后面，谁放在箭头左边！）
  * $A$ 是 $B$ 的**前提 / 基础 / 关键 / 必要条件 / 必不可少**（🚨 “必要条件”放箭头右边！）
  * 不 $A$，就不 $B$（$\neg A \rightarrow \neg B \iff B \rightarrow A$）

### 规则 3：特殊关联词“除非……否则……”（四川省考爱考变式）
* **口诀**：**“除非后面直接放箭头右边，否则后面全盘否定放箭头左边！”**
  * 表达式：除非 $A$，否则 $B \iff \neg B \rightarrow A$
  * 例：“除非考上公务员，否则不买房” $\rightarrow$ 买房推出考上公务员！

### 规则 4：联言选言与德摩根定律（且 vs 或）
* **“且”关系（同时满足）**：$A \text{ 且 } B$。只有两者都为真，整体才为真。
* **“或”关系（至少有一个）**：$A \text{ 或 } B$。只要有一个为真，整体就为真。
* **德摩根否定法则**：
  * $\neg(A \text{ 且 } B) \iff \neg A \text{ 或 } \neg B$
  * $\neg(A \text{ 或 } B) \iff \neg A \text{ 且 } \neg B$
* **选言否定肯定式**：已知 $A \text{ 或 } B$ 为真，若 $\neg A$，则必有 $B$！（否定一个，必然肯定另一个！）

## 二、 考场解题标准三步走

1. **第一步（翻译）**：看到题干的逻辑关联词，不要读长句意思，直接在草稿纸上写成箭头式：如 $A \rightarrow B$、$C \rightarrow D$。
2. **第二步（串联）**：利用传递律把箭头串起来（如 $A \rightarrow B$ 且 $B \rightarrow C$，则可串联为 $A \rightarrow B \rightarrow C$）。
3. **第三步（比对与逆否）**：拿已知确定事实去套箭头：
   * **肯前必肯后**（给 $A$ 推出 $B$）；
   * **否后必否前**（给 $\neg C$ 推出 $\neg B$ 和 $\neg A$）；
   * **否前肯后推不出任何必然！**
