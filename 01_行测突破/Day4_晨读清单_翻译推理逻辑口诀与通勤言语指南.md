## 模块一：晨间清醒脑 · 翻译推理 4 大公式极速默写（15分钟）

拿出一张白纸，在纸上默写以下箭头推导与等价公式：

### 1. 经典关联词翻译（前推后 vs 后推前）
* **【前推后】（$A \rightarrow B$）**：
  * 如果 $A$，那么 $B$
  * 只要 $A$，就 $B$
  * 为了 $A$，一定 $B$
  * 所有 $A$ 都是 $B$
* **【后推前】（$B \rightarrow A$）**：
  * **只有 $A$，才 $B$**（🚨 必考重点！）
  * $A$ 是 $B$ 的**前提 / 基础 / 关键 / 必要条件 / 必经之路**
  * 不 $A$，不 $B$（如：不破不立 $\rightarrow$ 立推破）

### 2. 逆否等价定理（考场唯一真理）
$$A \rightarrow B \iff \neg B \rightarrow \neg A$$
* 🚨 **口诀**：**肯前必肯后，否后必否前！**
* 🚨 **死穴**：否前、肯后，推不出任何必然结论（写“可能”，不写“必然”）！

### 3. “且”与“或”的否定转化（德摩根定律）
* $\neg(A \text{ 且 } B) \iff \neg A \text{ 或 } \neg B$（并非两者都有 $\rightarrow$ 至少有一个没有）
* $\neg(A \text{ 或 } B) \iff \neg A \text{ 且 } \neg B$（并非至少有一个 $\rightarrow$ 两者都没有）

### 4. 选言命题“否定肯定式”（做题神技）
* 当已知 **$A \text{ 或 } B$ 为真**：
  * 若 $\neg A$（否定了一方），**必定推出 $B$（肯定另一方）**！
  * 例：今晚要么吃火锅，要么吃烤肉。如果不吃火锅，**必定吃烤肉**！

## 模块二：申论省市卷 · 综合分析题（词句解释题）黄金三段论逻辑词

综合分析词句解释题（如“谈谈你对‘……’的理解”）阅卷标准严格按照三段论给分，大声朗读以下逻辑过渡词：

| 逻辑层次 | 考官采分意图 | 答题卡标准起手句式与连接词 |
| :---: | :--- | :--- |
| **第一步：释义层（是什么）** | 解释该句话/词语的**字面含义与本质内涵**（通常2分） | “这句话是指/本质上是指……”<br>“其核心内涵是……” |
| **第二步：分析层（为什么）** | 结合材料剖析**现状、原因、积极意义或危害影响**（通常8~10分） | “其积极意义在于：一是……；二是……”<br>“然而，当前面临……等现实困境”<br>“造成这种现象的原因主要有……” |
| **第三步：总结/对策层（怎么办）** | 提出解决问题、推动发展的**具体贯彻落实对策**（通常3~4分） | “因此，在未来的工作中我们应当……”<br>“要实现这一目标，关键在于：一是……；二是……” |
